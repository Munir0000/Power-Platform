## 🛠️ How I build

```text
1. Data model first     →  tables, relationships and security designed before any screen
2. Two questions        →  who can get in, and what can they see once they're in?
3. Everything in a solution  →  nothing built loose, every change deployable
4. Built to scale       →  queries filter on the server, never in the browser
5. Shipped properly     →  managed solution, Dev → Prod, tracked in Git
```
