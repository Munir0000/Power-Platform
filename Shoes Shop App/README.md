## The problem

Small retailers need a simple way to keep stock records accurate and to see how inventory is performing, without buying a full inventory system.

## Key features

- **Inventory management.** Add, view, update and delete shoe inventory items.
- **Stock tracking** with SharePoint as the data source.
- **Power BI dashboard** showing sales and stock trends.
- **Contact support** screen so users can reach support directly.
- A clean, simple interface for everyday use.
